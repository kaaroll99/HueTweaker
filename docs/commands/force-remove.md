# force remove

{% hint style="warning" %}
Administrators only.
{% endhint %}

Remove another member's username color. The bot deletes their HueTweaker color role.

**Syntax:** `/force remove <username>`

**Example:** `/force remove @kaaroll99`

**Good to know:**

* Cooldown: 10 seconds.
