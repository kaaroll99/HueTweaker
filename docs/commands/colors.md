# colors

Browse CSS color names with their HEX codes. Pick a group (red, green, blue…) from the menu to see its colors. Your color doesn't change.

**Syntax:** `/colors`

**Good to know:**

* Use any name or HEX from the list with [`/set`](set.md), e.g. `/set royalblue`.
* Very dark colors are labeled in light text so you can read them. The square next to the name shows the real color.
* The same list is on the [Colors](../main/colors.md) page.
* Cooldown: 10 seconds.
