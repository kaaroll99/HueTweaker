# match

Get username colors that match your avatar. The bot finds up to 4 main colors of your server avatar (or your profile avatar) and shows your name in each, plus a gradient of the two main ones.

* Press a numbered button to set that color.
* Press the 🌈 button (the last one) to set the gradient.

**Syntax:** `/match`

**Good to know:**

* Colors that would be hard to read on Discord's dark theme (very dark ones) are left out.
* The 🌈 gradient button needs Server Boost and a [top.gg vote](../main/voting.md), like [`/gradient`](gradient.md). Solid colors are free.
* Cooldown: 10 seconds.
