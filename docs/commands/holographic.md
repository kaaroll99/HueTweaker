# holographic

{% hint style="info" icon="gem" %}
Needs **Server Boost** on the server (enhanced role colors are a Discord boost perk) and your [**top.gg vote**](../main/voting.md). A vote lasts 12 hours.
{% endhint %}

Set Discord's holographic style: a shimmering, iridescent username. Discord allows only one holographic look, so there is nothing to choose. The bot shows a preview and applies it after you press **Accept**.

**Syntax:** `/holographic`

**Good to know:**

* `/set holographic` and `/gradient holographic` do the same.
* Others can copy it with `/set @you`.
* **Undo** in the result message brings back your previous color.
* Cooldown: 10 seconds.
