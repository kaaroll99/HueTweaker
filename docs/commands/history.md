# history

See the last 5 colors you used on this server, newest first. Press a numbered button to restore one.

**Syntax:** `/history`

**Good to know:**

* Every color change is saved: `/set`, `/gradient`, `/holographic`, `/select`, `/match`, favorites, and changes made by an admin with `/force set`.
* History is per server and is deleted when you leave the server.
* Restoring a gradient or holographic needs Server Boost and your [vote](../main/voting.md), like [`/gradient`](gradient.md).
* Cooldown: 10 seconds.
