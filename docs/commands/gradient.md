# gradient

{% hint style="info" icon="gem" %}
Needs **Server Boost** on the server (gradient role colors are a Discord boost perk) and your [**top.gg vote**](../main/voting.md). A vote lasts 12 hours.
{% endhint %}

Set a two-color gradient as your username color, or pick a ready-made one by name. The bot shows a preview and applies it after you press **Accept**.

**Syntax:** `/gradient <color> [secondary_color]`

* **Two colors:** each can be any [color format](../main/colors.md#color-formats).
* **Preset:** give only its name, e.g. `sunset`. The field suggests the names as you type. All presets are in [`/colors`](colors.md) → **Gradients**.

**Examples:**

* `/gradient f5df4d 00ff00`
* `/gradient royalblue tomato`
* `/gradient sunset`
* `/gradient @kaaroll99` (copies their gradient)

**Good to know:**

* The first time, the bot creates a role named `🎨 <your display name>`.
* For a single color, use [`/set`](set.md). For a shimmering style, try [`/holographic`](holographic.md).
* Cooldown: 10 seconds.
