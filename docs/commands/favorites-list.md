# favorites list

Show your favorite colors and gradients with a preview of your name in each.

* Press a numbered button to set that favorite.
* Use the menu to remove one from the list.

**Syntax:** `/favorites list`

**Good to know:**

* Add favorites with [`/favorites add`](favorites-add.md).
* A gradient or holographic favorite needs Server Boost on this server and your [vote](../main/voting.md). On a server without Server Boost, the bot tells you that gradients aren't available there; your favorite stays on the list.
* Cooldown: 10 seconds.
